# Predawn Water Potential Metadata

## Metadata Description
| Column Name | Description |
|---|---|
| site | Field site identifier (PIN or PIK). |
| date | Date of predawn water potential measurement (YYYY-MM-DD). |
| Cluster | Cluster identifier used by the campaign sampling scheme. |
| Genotype | Genotype code for the sampled plant/tree. |
| wp_pd | Predawn leaf water potential (MPa). Numeric; missing values may be encoded as `NA`. |
